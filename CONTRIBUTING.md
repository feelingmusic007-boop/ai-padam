# Contributing

Open an issue describing a bug, translation improvement, or proposed lesson. For changes, fork the repository, make a focused edit, and open a pull request explaining the change.

Lessons live in app.js in the lessons array, with English (en) and Malayalam (ml) versions. Keep both versions aligned. Do not invent tool capabilities, usage numbers, or personal experience. Tool-specific claims should include official sources and a review date.

Before submitting, open index.html and check both languages, search, lesson dialogs, quiz feedback, completion tracking after reload, narrow-screen layout, and keyboard navigation. Avoid adding personal data, passwords, or API keys.
