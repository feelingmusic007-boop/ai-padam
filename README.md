# AI Padam

An open-source beginner learning app with Malayalam and English text lessons about AI. This is an early prototype, not a complete course catalog.

## Run

Download this repository and open `index.html` in a modern browser. No installation, account, payment, or API key is required. Keep `index.html`, `style.css`, and `app.js` together.

## Features

- Switch the interface and lessons between Malayalam and English.
- Search three introductory lessons: writing, image prompts, and learning.
- Read example prompts and answer a short quiz.
- Mark lessons complete; progress is saved locally when browser storage is available.
- Responsive layout and keyboard-accessible lesson dialogs.

## Upload to GitHub

1. Sign in to GitHub and create a repository named `ai-padam`.
2. Choose Public if you want others to see and contribute to the source.
3. Choose Add file → Upload files and upload the extracted files from this folder. Do not upload only the ZIP.
4. Commit the files with a message such as `Add initial AI Padam learning app`.
5. Optional: use GitHub Pages to serve the app from the repository root.

Suggested repository description:
> Beginner-friendly AI learning application with Malayalam and English lessons, practical prompts, quizzes, and local progress tracking.

## Current limitations

Only three introductory text lessons and two languages are included. There is no chatbot, AI API integration, video course, login, backend, or cloud progress sync. Local storage behavior can vary when opening files directly. Content and translations should receive human review before a broader release. No user counts, adoption statistics, or program eligibility are claimed.
